Product: Shah Tunnel
Version: 1.4.2
Target: Linux amd64 / x86_64
Build: Go; CGO_ENABLED=0; -trimpath; linker flags -s -w -buildid= (debug/symbol tables stripped)
Security: TLS 1.2+, SHA-256 certificate fingerprint pinning, token authentication
Protocol: RREV3; Hub and Agent must use compatible versions
Lanes: four independently authenticated TCP/TLS lanes by default; reconnect backoff uses wider jitter to stagger recovery after shared resets
Flow control: bounded per-stream acknowledgement windows and process-wide queued payload budget
Admission control: active and pending streams reserve capacity before local target dials; per-lane limit of 512
Target recovery: up to four cancellable TCP dial attempts, 2-second timeout per attempt, bounded jittered delays; CLOSE and lane shutdown cancel pending dials
Close-race handling: expected EOF/net.ErrClosed/context cancellation is classified separately; closed-lane stream failures are suppressed and repeated target failures are rate-limited
Wire writer: bounded control/data queues; control frames are prioritized at frame boundaries
Command deck: embedded full-colour royal crown render with SHAH TUNNEL engraved on the lower gold band; frame title is COMMAND DECK only
Public package: precompiled binary only; Go source and tests are not included
Validation: go test -race -count=20 ./..., go vet ./..., bash -n S1T-START.sh install.sh; binary version and SHA-256 checked
Limit: local tests do not measure real-world loss, external Agent restarts or throughput on production VPS links.

Product: Shah Tunnel
Version: 1.3.10
Target: Linux amd64 / x86_64
Build: Go compiler with -trimpath and stripped debug/symbol tables (-s -w)
Security: TLS 1.2+, SHA-256 certificate pinning, token authentication
Target recovery: four bounded local-target dial attempts, 2-second per-attempt timeout, jittered increasing delays
Admission control: 512 active + pending opens per lane; pending target dials are cancellable
Diagnostics: safe target failure classes without printing the configured target address
Backpressure: up to eight 32-KiB outstanding data frames per stream; 32-MiB process-wide queued payload budget
Lanes: four independently authenticated TCP/TLS lanes by default; each lane reconnects independently
Protocol: RREV3; both Hub and Agent must be upgraded together because older RREV2 does not understand data acknowledgements or half-close
Validation: go test -race -count=20 ./..., go vet ./..., bash -n S1T-START.sh install.sh
Public package: precompiled binary only; source files are not included
Note: local tests do not measure real-world loss or throughput on production VPS links.

# Shah Tunnel

تانل TCP معکوس با احراز هویت، رابط ترمینال انگلیسی و رنگی، و سرویس systemd برای لینوکس `amd64`.

## امکانات

- نقش‌های Hub (ایران)، Agent (خارج) و Relay اختیاری.
- ارتباط رمزگذاری‌شده TLS 1.2+ با اثرانگشت گواهی و توکن تصادفی ۲۵۶ بیتی.
- پشتیبانی از چند نگاشت TCP، اتصال مجدد خودکار و شروع سرویس بعد از ریبوت.
- نمایش IP عمومی خروجی سرور و نام کشور در منو. دریافت اطلاعات از `https://ipapi.co/json/` با مهلت کوتاه و کش شش‌ساعته انجام می‌شود؛ در صورت در دسترس نبودن سرویس، `Unavailable / Unknown` نمایش داده می‌شود.
- نصب از ZIP رسمی پس از نصب موفق، پوشهٔ استخراج‌شده، ZIP، فایل SHA-256 و بسته‌های نصب قدیمی شناخته‌شدهٔ RavanReverse زیر `/root` را پاک می‌کند. فایل اجرایی نصب‌شده، تنظیمات و سرویس systemd باقی می‌مانند تا تانل اجرا شود. این پاک‌سازی و مجوزدهی، فایل‌ها را از مدیر root مخفی نمی‌کند.

## نصب از فایل انتشار

فایل ZIP را داخل `/root` آپلود کن و اجرا کن:

```bash
cd /root
unzip -o Shah-Tunnel-1.3.3-Linux-amd64.zip
cd /root/Shah-Tunnel-1.3.3
bash install.sh
```

در نصب تازه، منوی تنظیمات به‌صورت خودکار باز می‌شود. در ارتقا، تنظیمات موجود در `/etc/ravanreverse/config.json` حفظ می‌شود و سرویس مجدداً اجرا می‌شود.

باز کردن منو بعداً:

```bash
shah-tunnel
```

بررسی سرویس:

```bash
systemctl status ravanreverse --no-pager -l
journalctl -u ravanreverse -n 50 --no-pager
```

## انتشار در GitHub

فایل `.github/workflows/release.yml` تست‌ها را اجرا می‌کند و با push کردن تگ `v1.3.3` که با نسخهٔ داخل `main.go` یکسان باشد، فایل ZIP لینوکس amd64 و SHA-256 را می‌سازد و در GitHub Release قرار می‌دهد.

## نکات امنیتی

- توکن Hub را محرمانه نگه دار؛ مقدار آن باید در Hub و Agent یکسان باشد.
- اثرانگشت Agent باید با گواهی واقعی Hub تطابق داشته باشد.
- فایل تنظیمات زنده، توکن‌ها و کلید خصوصی را در GitHub منتشر نکن.
- اطلاعات IP و کشور، بر اساس IP خروجی عمومی سرور از دید API موقعیت‌یابی است و لزوماً مکان فیزیکی دقیق سرور را ثابت نمی‌کند.

# شاه تونل (Shah Tunnel) — نسخهٔ 1.3.4

**زبان / Language:** [🇮🇷 فارسی](README-fa.md) · [🇬🇧 English](README.md)

**تانل معکوس TCP با احراز هویت برای لینوکس `amd64`** · نصب یک‌دستوری با فایل اجرایی · مدیریت از طریق systemd

> نسخهٔ **1.3.4** — تشخیص IP و کشور اکنون چند سرویس جایگزین را امتحان می‌کند؛ اگر تشخیص کشور ناموفق باشد، تلاش می‌کند دست‌کم IP عمومی را نمایش دهد. کشور و IP نیز در منو کنار هم دیده می‌شوند.

## نصب آسان با یک دستور

روی سرور Ubuntu/Debian با معماری `x86_64` و با کاربر `root` اجرا کن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/shah1dev/ShahTunnel/main/S1T-START.sh)
```

نصب‌کننده فایل اجرایی `S1T-CAPSULE/S1T-CORE` را می‌گیرد، صحت آن را با SHA-256 موجود در `S1T-CHECKSUM.sha256` بررسی می‌کند، برنامه و سرویس systemd را نصب می‌کند، تنظیمات موجود در `/etc/ravanreverse/config.json` را حفظ می‌کند و منوی تعاملی را باز می‌کند. روی سرور نیازی به ZIP یا سورس نیست. پیش‌نیازها: دسترسی root، ابزار `curl`، ابزار `sha256sum` و systemd.

برای بازکردن منو در دفعات بعد:

```bash
shah-tunnel
```

## توضیح فنی تانل

شاه تونل، ارتباط‌های خام TCP را از یک نقطهٔ ورودی عمومی به مقصدی که از سرور خروجی قابل دسترسی است منتقل می‌کند. این برنامه یک تونل TCP در سطح برنامه است؛ کارت شبکهٔ مجازی یا VPN عمومی برای تمام ترافیک IP ایجاد نمی‌کند.

```text
کاربر TCP → شنوندهٔ عمومی Hub → اتصال TLS احراز هویت‌شده → Agent → مقصد TCP تنظیم‌شده
```

- **Hub (ورودی):** روی پورت‌های TCP تعیین‌شده گوش می‌دهد و اتصال خروجی Agent را می‌پذیرد.
- **Agent (خروجی):** خودش اتصال احراز هویت‌شده را به Hub برقرار می‌کند و برای هر جریان عبوری، مقصد TCP محلی تنظیم‌شده را باز می‌کند.
- **نگاشت پورت‌ها:** چند نگاشت قابل تعریف است؛ شناسهٔ هر نگاشت باید در هر دو سمت یکسان باشد.
- **امنیت ارتباط:** ترافیک بین Hub و Agent با TLS نسخهٔ 1.2 یا بالاتر، تطبیق اثرانگشت SHA-256 گواهی و توکن احراز هویت مشترک تصادفی ۲۵۶ بیتی محافظت می‌شود.
- **پایداری:** بررسی سلامت ارتباط، اتصال مجدد خودکار با تأخیر افزایشی و پشتیبانی از راه‌اندازی مجدد سرویس توسط systemd.
- **مدیریت:** منوی راه‌اندازی تعاملی، شروع/توقف/راه‌اندازی مجدد، مشاهدهٔ وضعیت و لاگ‌ها، و حذف سرویس و فایل‌های متعلق به خود شاه تونل.
- **مشخصات سرور:** منو IP عمومی خروجی سرور و کشور را از چند سرویس HTTPS دریافت می‌کند. نتیجه تا شش ساعت کش می‌شود؛ اگر سرویس‌های تشخیص کشور پاسخ ندهند، یک مسیر جایگزین برای دریافت IP امتحان می‌شود. اگر سرور به هیچ‌کدام دسترسی نداشته باشد، ممکن است اطلاعات همچنان نامشخص نمایش داده شود.

## نسخه و ساختار فایل‌ها

- نسخهٔ انتشار: **1.3.4**
- هدف: Linux `amd64` / `x86_64` با systemd
- مسیر فایل اجرایی نصب‌شده: `/usr/local/bin/ravanreverse`
- فرمان کاربر: `/usr/local/bin/shah-tunnel`
- نام‌های سازگار با نصب‌های قبلی: سرویس `ravanreverse` و تنظیمات `/etc/ravanreverse/config.json`
- ساختار مخزن عمومی: داخل `S1T-CAPSULE/` فقط فایل اجرایی کامپایل‌شده قرار می‌گیرد؛ نصب‌کننده، checksum و مستندات بیرون از آن هستند.

لوگوی مخزن در مسیر [`docs/img/shah-tunnel-logo.svg`](docs/img/shah-tunnel-logo.svg) نگهداری می‌شود و بالای این توضیحات نمایش داده می‌شود.

## نکات امنیتی

- توکن Hub و فایل `/etc/ravanreverse/config.json` را محرمانه نگه دار. توکن فعال، کلید خصوصی یا تنظیمات واقعی سرورها را در مخزن منتشر نکن.
- TLS ارتباط بین Hub و Agent را محافظت می‌کند؛ IP عمومی سرور را از ارائه‌دهندهٔ اینترنت یا ناظرانی که ترافیک شبکه را می‌بینند پنهان نمی‌کند.
- مکان‌یابی IP تقریبی است و مکان فیزیکی یا مالکیت سرور را ثابت نمی‌کند. برای درخواست مکان‌یابی، IP عمومی سرور به سرویس پاسخ‌دهنده فرستاده می‌شود.
- باینری stripped سورس Go را به‌صورت متن خوانا داخل خود ندارد، اما هیچ فایل اجرایی‌ای را نمی‌توان مطلقاً غیرقابل مهندسی معکوس تضمین کرد. برای محرمانه‌ماندن سورس، سورس و آرشیوهای قدیمی آن را در مخزن عمومی منتشر نکن.
- حذف فایل از آخرین commit، نسخه‌های قبلی را از تاریخچهٔ Git حذف نمی‌کند. سورس منتشرشدهٔ قبلی ممکن است در commitهای قدیمی، forkها یا cacheها باقی بماند و برای حذف آن‌ها باید جداگانه تاریخچه و نسخه‌های کپی‌شده را مدیریت کرد.

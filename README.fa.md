# Shah1Tunnel — فارسی

این یک مستند فارسی از مخزن Shah1Tunnel است. نسخهٔ انگلیسی را برای توضیحات فنی‌تر ببینید: README.md

فهرست سریع
- نصب سریع: دستورالعمل‌های کپی/پیست برای اجرای نصب‌کننده
- پیش‌نیازها: ابزارهای مورد نیاز و فضای دیسک
- نکات ایمنی و آزمایش‌ها: چه چیزهایی بررسی شده و چه چیزهایی نیاز به اجرای واقعی روی سرور دارد
- قابلیت‌های تأییدشده: فهرست ویژگی‌هایی که بر اساس بررسی فایل‌ها یافت شد

## نصب سریع
```bash
git clone https://github.com/shah1dev/Shah1Tunnel.git
cd Shah1Tunnel
# در صورتی که فایل آرشیو داخل S1T-CAPSULE به نام 'null' موجود است:
if [ -f "S1T-CAPSULE/S1T-SOURCE.tar.gz" ]; then
  sudo bash S1T-START.sh
elif [ -f "S1T-CAPSULE/null" ]; then
  ln -sf "$(pwd)/S1T-CAPSULE/null" "$(pwd)/S1T-CAPSULE/S1T-SOURCE.tar.gz"
  sudo bash S1T-START.sh
else
  echo "ERROR: required package archive missing: S1T-CAPSULE/S1T-SOURCE.tar.gz or S1T-CAPSULE/null" >&2
  exit 1
fi
```

توضیحات کامل‌تر و مستندات فنی در فایل `docs/TECHNICAL.md` قرار دارد.

## آنچه بررسی شد (خلاصه)
- فایل‌های سطح بالا: README.md، S1T-START.sh، S1T-CHECKS.sha256، S1T-INFO-FA.txt، S1T-CAPSULE/null
- اسکریپت نصب (S1T-START.sh): بررسی کامل برای مراحل اعتبارسنجی، ایجاد فضای کاری، استخراج بسته و راه‌اندازی
- محتویات کپسول (S1T-CAPSULE/null): شامل اسکریپت‌های نصب، مستندات داخلی و منطق نصب است (متن و بخش‌های فنی دیده شدند)

## قابلیت‌های تأییدشده (بر اساس بررسی فایل‌ها)
- بررسی یکپارچگی بسته با sha256: پیاده‌سازی شده (S1T-START.sh)
- تخصیص فضای کاری دیسکی حداقل 16 MiB: پیاده‌سازی شده
- استخراج امن آرشیو به workspace و بازنشانی نام‌های رمزگذاری‌شده: پیاده‌سازی شده
- شناسایی معماری و دانلود باینری رسمی برای amd64/arm64: پیاده‌سازی شده (اسکریپت داخل کپسول)
- نصب manager محلی و ایجاد unit systemd: پیاده‌سازی شده
- منطق حذف (uninstall) و پاکسازی کامل: پیاده‌سازی شده

## موارد نیازمند بررسی در محیط واقعی
- اجرای واقعی اسکریپت نصب و اعتبارسنجی SHA-256 با `sha256sum` (نیازمند محیط لینوکسی)
- استخراج کامل `Shah1Tunnel-Core/` برای بررسی سورس Go، حامل‌ها (carriers)، روش‌های رمزنگاری و پیاده‌سازی پروتکل
- تست end-to-end تونل (ICMP/UDP/TCP/TLS/WSS/H2/GRPC) در محیط شبکه واقعی

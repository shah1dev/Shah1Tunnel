Shah Tunnel v1.3.4 — راهنمای آپلود فایل‌های به‌روزرسانی

مخزن: https://github.com/shah1dev/ShahTunnel

این ZIP را روی سرور اجرا نکن. آن را روی گوشی/کامپیوتر باز کن و فایل‌ها را در مخزن GitHub با همین مسیرها آپلود یا جایگزین کن:

- S1T-START.sh                    (ریشه؛ جایگزین نسخه فعلی)
- S1T-CHECKSUM.sha256             (ریشه؛ جایگزین نسخه فعلی)
- install.sh                      (ریشه؛ جایگزین نسخه فعلی)
- README.md                       (ریشه؛ فایل جدید، توضیحات انگلیسی)
- README-fa.md                    (ریشه؛ جایگزین نسخه فعلی، توضیحات فارسی)
- UPLOAD-INSTRUCTIONS-fa.txt      (ریشه؛ راهنمای آپلود)
- BUILD-INFO.txt                  (ریشه؛ مشخصات ساخت)
- S1T-CAPSULE/S1T-CORE             (جایگزین باینری قبلی)

در پوشه S1T-CAPSULE فقط S1T-CORE باشد. main.go، فایل تست، ZIP، سورس یا فایل checksum داخل این پوشه قرار نده.
لوگوی قبلی مخزن را در مسیر docs/img/shah-tunnel-logo.svg نگه دار؛ هر دو README به همان مسیر ارجاع می‌دهند.

در بالای هر README انتخاب زبان کلیک‌پذیر است: English و فارسی.

پس از Commit شدن همهٔ فایل‌ها، نصب یا ارتقا را روی سرور با کاربر root اجرا کن:
bash <(curl -fsSL https://raw.githubusercontent.com/shah1dev/ShahTunnel/main/S1T-START.sh)

فرمان نصب، باینری را دانلود می‌کند، SHA-256 را کنترل می‌کند، فایل اجرایی و سرویس systemd را نصب/به‌روزرسانی می‌کند، تنظیمات قبلی را حفظ می‌کند و منو را باز می‌کند.

توجه: این بسته برای Linux amd64/x86_64 و systemd است. اگر IP یا کشور همچنان Unknown باشد، دسترسی خروجی سرور به سرویس‌های HTTPS مکان‌یابی را بررسی کن. نسخهٔ جدید سه سرویس کشور/IP را به ترتیب امتحان می‌کند و در صورت شکست، IP را جداگانه دریافت می‌کند.

ShahTunnel — بستهٔ طرح ASCII رنگی

فایل‌ها:
- README.md و README-fa.md: فایل‌های آمادهٔ جایگزینی در ریشهٔ مخزن
- docs/img/shah-tunnel-ascii.svg: طرح رنگی برای GitHub با حروف ساخته‌شده از ASCII
- SERVER-BANNER.sh: پیش‌نمایش تاج و اسم رنگی در ترمینال؛ اجرا: bash SERVER-BANNER.sh
- SERVER-BANNER.txt: بنر متنی دارای کدهای رنگ ANSI؛ با cat معمولی در ترمینال نمایش دهید
- SERVER-BANNER-GO-SNIPPET.txt: تابع نمونه برای جایگزینی بنر در سورس Go

نکتهٔ مهم: اسکریپت پیش‌نمایش به‌تنهایی بنر داخل منوی باینری نصب‌شده را تغییر نمی‌دهد. برای تغییر خود منو باید تابع چاپ بنر در سورس Go جایگزین و باینری دوباره ساخته شود. سورس برنامه در مخزن فعلی موجود نیست و اتصال GitHub هم اجازهٔ commit مستقیم نداد؛ بنابراین این بسته آمادهٔ آپلود است، اما هنوز در GitHub یا سرور نصب نشده است.

GitHub رنگ‌های ANSI داخل README را اجرا نمی‌کند؛ به همین علت نسخهٔ رنگی به‌صورت SVG درج شده و متن ASCII نیز زیر آن قرار دارد.
